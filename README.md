# 🏆 Colleague Appreciation Platform

A modern, interactive colleague recognition platform built with React, TypeScript, and Tailwind CSS. This application enables organizations to foster a culture of appreciation by allowing employees to recognize and celebrate each other's contributions.

## ✨ Features (biz GA please help a bit here.)

### 🎯 Core Functionality
- **Recognition Feed** - Real-time stream of employee recognitions and appreciations
- **Interactive Dashboard** - Comprehensive analytics and insights
- **Recognition Categories** - Organized recognition by teamwork, innovation, leadership, etc.
- **Social Interactions** - Like and engage with recognition posts
- **Colleague Directory** - Browse and recognize team members

### 📊 Analytics & Insights
- **Recognition Distribution** - Interactive doughnut charts showing recognition by category
- **Trend Analysis** - Time-series charts tracking recognition patterns over months
- **Personal Statistics** - Individual recognition metrics (given vs received)
- **Badge System** - Achievement badges based on recognition activity

### 🎨 User Experience
- **Responsive Design** - Seamless experience across desktop, tablet, and mobile
- **Real-time Updates** - Live recognition feed with timestamps
- **Interactive Charts** - Built with Recharts for smooth data visualization
- **Modern UI** - Clean, professional interface using Tailwind CSS


## 📋 Prerequisites

- **Node.js** (v16.x or higher)
- **npm** or **yarn** package manager

## 🛠️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd CTO_Rocket_New_POC
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run start
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` to view the application
